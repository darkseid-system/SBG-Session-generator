# SBG-MD — Real Session

This package keeps the existing SBG-MD interface and adds a real `/api/pair` backend.

## Structure

- `public/index.html` — original SBG-MD page, preserved
- `public/session.html` — pairing-code interface
- `server.js` — Express + Baileys backend
- `package.json` — dependencies
- `sessions/` — created automatically at runtime for WhatsApp credentials

## Run

```bash
npm install
npm start
```

Open the server URL and tap **SESSION** / **GENERATE SESSION**.

## Important

A real WhatsApp session cannot be generated by HTML alone. The Node.js backend must stay online and must have write access to the `sessions/` directory.

For deployment on Railway, use:

- Build/install: `npm install`
- Start: `npm start`

The server listens on `process.env.PORT`.

Do not publish the `sessions/` directory or its contents. Those files contain authentication credentials. Do not commit them to GitHub.
